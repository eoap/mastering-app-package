    water-bodies¶

    CWL Class¶

    Workflow

    Requirements¶

    • ScatterFeatureRequirement
    • SchemaDefRequirement

    Inputs¶

    Id Type Label Doc
    aoi Polygon:
    • type: enum:
      • Polygon
    • coordinates: array of array of array of double
    • bbox: array of double
    		 area of interest GeoJSON Polygon defining the area to crop; raster pixels outside the polygon are masked.
    epsg enum:
    • 4326
    		 EPSG code EPSG code
    bands array of enum:
    • green
    • nir
    • nir08
    		 bands used for the NDWI bands used for the NDWI
    item Directory STAC item reference Reference to a STAC item

    Steps¶

    Id Runs Label Doc
    node_crop #crop Crop bands Crop the selected bands to the area of interest.
    node_normalized_difference #norm_diff Compute NDWI Compute the normalized difference water index from the cropped bands.
    node_otsu #otsu Detect water bodies Apply the Otsu threshold to produce a binary water body mask.
    node_stac #stac Catalog results Create a STAC catalog describing the detected water bodies.

    Outputs¶

    Id Type Label Doc
    stac_catalog Directory Results STAC catalog Directory containing the results STAC catalog and its referenced raster assets.
